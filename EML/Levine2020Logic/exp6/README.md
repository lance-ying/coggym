# Study 4b (Exp 6): Collective action curves.

## Abstract
Participants rated expected utility or frustrated means for varying numbers of actors under two threshold conditions (4/7 vs 10/13). Responses were collected on a -50 to 50 slider.

## Overview
- Question types: Everyone's EU, John's EU, Frustrated Means.
- N values: 1, 3, 8, 9, 14, 20.
- Control question about number of fishers was excluded from the flow.
- Human data from `original_experiments/universalization/CA_small.csv`.

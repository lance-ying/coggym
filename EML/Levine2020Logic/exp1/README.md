# Study 1 (Exp 1): Explanation endorsement.

## Abstract
150 MTurk participants read 12 short moral-violation stories and judged whether four explanation types (outcome, unfairness, universalization, harm) were convincing. Each trial presents the story and four binary judgments.

## Overview
- 12 stories, each with 4 explanation queries.
- Responses are binary (convincing / not convincing).
- Human data from `original_experiments/universalization/reasons1.csv`.

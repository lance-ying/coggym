# Study 4a (Exp 5): Moral permissibility across N interested parties.

## Abstract
Participants repeatedly evaluated a fishing-hook scenario while the number of interested parties (N) varied. Two threshold conditions (4/7 vs 10/13) were between-subjects, and N values were randomized without replacement.

## Overview
- N values: 0, 2, 7, 8, 13, 19 (within-subject).
- Each N has comprehension + moral/rule/outcome questions.
- Blocks for each N are marked randomized in the experiment flow.
- Human data from `original_experiments/universalization/4-7b.csv` and `10-13b.csv`.

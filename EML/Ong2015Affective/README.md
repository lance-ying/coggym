# Ong, Zaki, & Goodman (2015) Affective cognition: Exploring lay theories of emotion

## Abstract
This study formalizes how observers reason about others' emotions using structured lay theories. Across four experiments, participants watched a character play a simple gambling game and inferred emotions or outcomes. The work tests forward inferences from outcomes to emotions, reverse inferences from emotions to outcomes, and cue integration when outcomes are paired with facial expressions or utterances.

## Overview
- Converted four experiments (exp1-exp4) from the original stimuli and data.
- Trial definitions encode wheel outcomes and, when applicable, face or utterance cues.
- Human response files are populated from the released CSV data; demographic details are not included in the raw data.

## Directory Structure
- `exp1/`: Outcome-to-emotion judgments with 50 pre-generated wheel scenarios.
- `exp2/`: Emotion-to-outcome judgments using emotion profiles derived from Experiment 1.
- `exp3/`: Cue integration with wheel outcomes and facial expressions (18 faces).
- `exp4/`: Cue integration with wheel outcomes and verbal utterances (10 utterances).
